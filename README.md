# Классификация заявок на кредит

Лабораторная работа №1 по дисциплине «Теория распознавания», 3 курс, 1 семестр.

## Задача
Предсказание того, будет ли одобрена заявка на кредит, по данным
о заёмщике и самом кредите.

## Данные
Датасет [Loan Approval Classification](https://www.kaggle.com/datasets/taweilo/loan-approval-classification-data)
содержит 45 тысяч заявок. В нём есть возраст, доход, образование, стаж
и кредитная история заёмщика, а также сумма, ставка и цель кредита.
Классы несбалансированы, одобрена примерно каждая пятая заявка.
Числовые признаки стандартизированы, категориальные закодированы one-hot.

## Модели
- KNN с подбором числа соседей, метрики расстояния и весов через GridSearchCV
- Random Forest с подбором числа деревьев, критерия и глубины, качество
  оценивается по out-of-bag выборке

Модели сравниваются по accuracy, precision, recall, F1 и ROC-кривым.
